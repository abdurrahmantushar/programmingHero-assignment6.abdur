# FitLog

FitLog is a workout library website where users can explore workouts, view workout details, add workouts to their plan, and save workouts for later.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Lucide React
* React Toastify
* REST API
* LocalStorage

## Key Features

* Browse workout library
* View workout details
* Add workouts to today's plan
* Save workouts for later
* Mark workouts as done
